# Shift Runner (web)

Play in the browser: **https://marse337.github.io/shiftrunner-play/**

A 2D platformer where the bear transforms with power-ups, beats bosses and races to the goal.

- **Desktop:** keyboard (A/D or arrows to move, Space/W to jump, J/K/X to attack, L/C to carry, Shift to run,
  Esc to pause) or a gamepad.
- **Phones and tablets:** turn the device sideways. Drag on the left half to move (push all the way to run), and
  tap JUMP, ATTACK, CARRY and the RUN lock on the right. The II button pauses. On Android the first tap goes full
  screen. On iPhone, use Share, then Add to Home Screen.

This repo only holds the built web export (Godot 4.7, single-threaded build for GitHub Pages).
